# ContextShield

Projeto React + Vite + TypeScript preparado para execução no StackBlitz.

## Executar localmente

```bash
npm install
npm run dev
```

## Executar no StackBlitz

O projeto usa `package.json` e `.stackblitzrc` para iniciar automaticamente com:

```bash
npm run dev
```

As dependências são instaladas automaticamente pelo StackBlitz.
